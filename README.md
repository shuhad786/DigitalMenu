# 📖 [Digital menu] <a name="about-project"></a>

> An app requested by Christoffel, a private chef renowned for his personalised culinary experiences, using React Native this application will have a dynamic menu that will be displayed on the app and available for download and that can be updated by the chef A.K.A a CRUD based application.

### Tech Stack <a name="tech-stack"></a>

- React-Native
- Javascript
- Typescript

## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

copy the link below and clone it on to your local machine with vscode source control

- https://github.com/shuhad786/DigitalMenu.git

### Prerequisites

In order to run this project you need:

Android Studio
Vscode
Github account

### Setup

clone the link below

- https://github.com/shuhad786/DigitalMenu.git

### Install

Install this project with:

use npm i to install node_modules

### Usage

To run the project, execute the following command:

open 2 separate terminals in vscode

in one of them run to install the application: npx react-native run-android

in the other run to start the metro: npx react-native start
